01

SOC Analyst Portfolio

Detection engineering home lab

A Wazuh SIEM watching a Windows 10 endpoint, a Windows Server domain controller and a Kali attacker. I run the technique, then do the analyst side of it: triage the alert, pull the timeline out of the logs, collect the IOCs, map the technique, and write or tune the rule that would have caught it sooner. Seven case files so far, each with the simulation, the triage, the mapping and the remediation a responder would need.

02

Post-Compromise Operations on Windows & Linux

Controlled attack lifecycle

A full lifecycle across two hosts: phishing-style initial access, msfvenom payloads for Windows and Linux, two Meterpreter shells, host and network reconnaissance, WinPEAS enumeration, document exfiltration and browser credential extraction, Mimikatz hash dumping, a PowerShell keylogger, and persistence through a root backdoor account. The write-up keeps the defender's side in view: what every step leaves behind in event logs, process trees and network traffic.

Remote Access Trojan: Malware Analysis

Static and dynamic analysis, isolated VM

An NjRAT 0.7d sample taken apart in an isolated virtual machine: static inspection in PE Studio, behaviour in Procmon, network traffic through FakeNet-NG, persistence, indicators of compromise, ATT&CK technique mapping, and YARA and VirusTotal checks on what the sample actually does.
